# 📖 About PersonaOS

**PersonaOS** is an interactive cyberpunk-inspired developer portfolio designed to go beyond a traditional resume.

Instead of only showcasing projects, PersonaOS enables visitors to explore an immersive developer experience through AI-powered conversations, interactive coding assessments, debugging games, rapid-fire programming challenges, research publications, and animated storytelling.

The goal is to demonstrate practical engineering skills, creativity, and problem-solving abilities in an engaging way.

# 🚀 Getting Started

Clone Repository

```bash
git clone https://github.com/bhavya27092027/PersonaOS.git
```

Navigate

```bash
cd PersonaOS
```

Install Dependencies

```bash
npm install
```

Run

```bash
npm run dev
```

Build

```bash
npm run build
```

Preview

```bash
npm run preview
```
