## 🌌 Welcome to PersonaOS

**PersonaOS** is a futuristic, cyberpunk-inspired developer portfolio built to go beyond the traditional resume.

It transforms a developer portfolio into an interactive digital universe where visitors can explore projects, technical expertise, professional experience, certifications, research publications, AI-powered conversations, and gamified coding challenges.

With immersive animations, glassmorphism, neon-inspired visuals, and persona-based navigation, PersonaOS creates a personalized experience for every visitor.

> 💡 Not just a portfolio. An interactive experience of my developer journey.

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/bhavya27092027/PersonaOS.git
```

### 2. Navigate to Project

```bash
cd PersonaOS
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

### 5. Production Build

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```
